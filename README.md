## Featured Projects

### 🧠 FedGIN — Federated Learning for Medical Imaging *(Ongoing)*
> `PyTorch` · `Federated Learning` · `Medical Imaging` · `Distributed Systems`

Privacy-preserving federated framework for multi-modal organ segmentation across distributed hospital datasets. Implements server-side dynamic non-linear intensity augmentation to address cross-site scanner variability and mitigate client drift from data heterogeneity.

---

### 🔧 [Modular LoRA Adapter Merging for LLMs](https://github.com/sindgisrishtis/modular-lora-adapter-merging)
> `PyTorch` · `HuggingFace` · `PEFT` · `TinyLLaMA`

Modular system for fine-tuning and merging task-specific LoRA adapters on a frozen TinyLLaMA base. Implemented weighted and layer-wise merging strategies; analyzed task interference across transformer attention layers under constrained compute.

---

### 🤟 [Samvaad — Multimodal ISL Translation System](https://github.com/sindgisrishtis/Samvaad)
> `TensorFlow` · `MediaPipe` · `OpenCV` · `Streamlit`

Real-time Indian Sign Language ↔ Text ↔ Speech translation system. Bidirectional pipeline supporting Sign→Text, Speech→Sign, and Text→Sign modes, with analytics dashboard and practice interface.

---

### 🏭 [Industrial Surface Defect Detection](https://github.com/sindgisrishtis/Industrial-Defect-Detection)
> `PyTorch` · `OpenCV` · `Docker` · `TorchScript`

Real-time steel surface defect detection with automated alerting and logging. Optimized for edge deployment using Docker and TorchScript.

---

### 🏗️ [AI-Powered ERP Workflow Automation](https://github.com/sindgisrishtis/ai-erp-workflow-automation)
> `FastAPI` · `React` · `PostgreSQL` · `REST APIs`

Scalable enterprise ERP platform with role-based workflow orchestration, inventory management, purchase approval pipelines, and AI-assisted automation modules.

---

### 📊 [Fleet Telematics Analytics Pipeline](https://github.com/sindgisrishtis/fleet-analytics)
