# Featured Projects

## 🔬 FedGIN — Federated Learning for Multimodal Medical Image Segmentation

**[Repository](https://github.com/sindgisrishtis/FedGIN-Multimodal-Segmentation)**

A federated learning framework for **multimodal organ segmentation across distributed hospital datasets**.

The project explores **Dynamic Global Non-linear Augmentation** at the server side to address scanner variability and data heterogeneity across participating clients, with the goal of reducing client drift during federated training.

**Stack:**  
`PyTorch` `Federated Learning` `Medical Imaging` `Deep Learning`

**Focus:** Federated optimization · Multimodal segmentation · Non-IID data · Client drift · Privacy-preserving ML

## ⚡ Orchestrix — Event-Driven Workflow Orchestration Platform

An enterprise-style workflow orchestration system inspired by architectural ideas from platforms such as **Temporal, n8n, Zapier and Trigger.dev**.

Workflows can be defined, triggered and executed through backend services using **message queues, background workers and event-driven communication**.

The project focuses more on understanding the architecture behind workflow systems than simply building another CRUD application.

**Stack:**  
`Python` `FastAPI` `PostgreSQL` `SQLAlchemy` `RabbitMQ` `Redis` `Docker` `React` `TypeScript`

**Focus:** Event-driven architecture · Workflow execution · Message queues · Background workers · Distributed backend systems

## 🤟 Samvaad — Multimodal Indian Sign Language Translator

**[Repository](https://github.com/sindgisrishtis/samvaad-multimodal-isl-translator)**

A multimodal Indian Sign Language translation system combining **computer vision, deep learning and speech processing**.

The system supports multiple interaction paths including **Sign → Text, Sign → Speech, Text → Sign and Speech → Sign**.

The sign-recognition pipeline uses **MediaPipe Hands** to extract 21 hand landmarks, which are processed by a TensorFlow/Keras classifier covering **36 sign classes (A–Z and 0–9)**.

The application also includes **Practice Mode and an Analytics Dashboard**, packaged as an interactive Streamlit application.

**Stack:**  
`TensorFlow` `MediaPipe` `OpenCV` `Streamlit` `Docker`

**Focus:** Computer vision · Landmark extraction · Deep learning · Speech interaction · Real-time inference
